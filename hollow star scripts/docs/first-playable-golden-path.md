# First Playable Golden Path

## Definition

The **golden path** is a regression and playtest route: one representative
player journey that must work end to end without developer tools. It is not a
new game mode, a canon declaration, a permanent default, or a reduction of the
Hollow Star Reliquary's five-floor scope.

For the first playable refining pass, that route is:

1. Launch the local browser client.
2. Choose Story Mode, New Game, Champion, and Doran.
3. Read or inspect the threshold, then begin its encounter.
4. Select visible targets and use movement, attacks, maneuvers, turns, and any
   offered reactions entirely through browser controls.
5. Win the encounter and receive the host-awarded room reward exactly once.
6. Bank the threshold checkpoint, save the run, return to the main menu, and
   continue the same run with the same public state.
7. See a clear continuation prompt that the deeper Reliquary remains ahead.

## Scope guard

This is a refinement pass over existing host, module, combat, persistence, and
browser systems. It does not replace the procedural five-floor engine, make the
threshold the whole game, authorize Forge canon promotion, add offline AFK
settlement, or settle author-gated design questions.

## Preserved options

- Custom-character Story entry remains supported and receives the same host
  contracts after the Doran regression route is stable.
- Wren and later Champion routes remain valid alternatives; Doran is only the
  first automated acceptance fixture.
- Simulation Mode remains the open non-canon rehearsal surface.
- The threshold may later lead into the existing five-floor generator or a
  larger authored module without changing this test definition.
- A future golden path may use another hero or route. Changing the acceptance
  fixture does not change game scope or canon.

## Acceptance boundary

The route passes only when it works on desktop and narrow browser layouts with
no raw IDs required from the player, no browser-owned mechanics, no hidden-state
leakage, no duplicated rewards, and exact save/resume continuity.
